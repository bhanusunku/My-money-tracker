Setup Guide

Connect to Google Sheets in 5 min

🔗 Your Google Sheet Web App URL

Paste your Google Apps Script Web App URL here. Follow the steps below to get it.

📋 How to set up (5 minutes, free)

  1. 1 Go to sheets.google.com → create a new sheet named Expense Tracker
  2. 2 Add these headers in Row 1:
    Date | Day | Type | Category | Amount | Mode | Where | Why | Notes | Month
  3. 3 In the sheet, click Extensions → Apps Script
  4. 4 Delete all existing code, paste the script below
  5. 5 Click Deploy → New deployment → Web app
  6. 6 Set "Who has access" to Anyone → click Deploy
  7. 7 Copy the Web App URL and paste it above

📱 Add to Home Screen (use like an app)

iPhone: Open this file in Safari → tap Share → "Add to Home Screen"

Android: Open in Chrome → tap ⋮ menu → "Add to Home screen"

It will appear as an app icon on your phone!

📊 Connect to Excel

In your Excel tracker, go to Data → Get Data → From Web and paste your Google Sheet's published CSV link:
https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/export?format=csv

Or simply download the sheet as .xlsx monthly and copy-paste the data rows into your Excel tracker's Daily Log sheet.
